# TCP/IP Model

## What is the TCP/IP Model?

The TCP/IP model is a networking framework used to explain how devices communicate over networks and the Internet.

It has four layers:

1. Application Layer
2. Transport Layer
3. Internet Layer
4. Network Access Layer

## 1. Application Layer

This layer provides network services to applications.

Examples:

- HTTP
- HTTPS
- DNS
- DHCP
- FTP
- SMTP

## 2. Transport Layer

This layer provides communication between applications running on different devices.

Main protocols:

- TCP
- UDP

TCP provides reliable, connection-oriented communication.

UDP provides faster, connectionless communication with less overhead.

## 3. Internet Layer

This layer is responsible for logical addressing and routing packets between networks.

Main protocol:

- IP

Examples:

- IPv4
- IPv6
- ICMP

## 4. Network Access Layer

This layer handles communication over the physical/local network.

Examples:

- Ethernet
- Wi-Fi
- MAC addressing

## OSI vs TCP/IP

The OSI model has seven layers, while the TCP/IP model commonly uses four layers.

The TCP/IP model is closely associated with the protocols used for real-world Internet communication.

## What I Learned

- TCP/IP is a practical networking model used for Internet communication.
- TCP and UDP operate at the Transport Layer.
- IP operates at the Internet Layer.
- HTTP, HTTPS, and DNS operate at the Application Layer.
- The Network Access Layer handles local network communication.
