# TCP vs UDP

## What is TCP?

TCP (Transmission Control Protocol) is a connection-oriented transport protocol that provides reliable and ordered delivery of data.

### TCP Characteristics

- Connection-oriented
- Reliable delivery
- Data arrives in order
- Uses acknowledgements
- Performs error checking
- More overhead than UDP

## What is UDP?

UDP (User Datagram Protocol) is a connectionless transport protocol that sends data without establishing a connection.

### UDP Characteristics

- Connectionless
- Faster and lightweight
- No guarantee of delivery
- No guarantee of packet order
- Lower overhead than TCP

## TCP vs UDP

| Feature | TCP | UDP |
|---|---|---|
| Connection | Connection-oriented | Connectionless |
| Reliability | Reliable | No delivery guarantee |
| Ordering | Maintains order | No ordering guarantee |
| Speed | Generally slower | Generally faster |
| Overhead | Higher | Lower |

## Common Examples

### TCP

- HTTPS
- HTTP
- SSH
- FTP

### UDP

- DNS queries
- DHCP
- VoIP
- Streaming and real-time applications

## Cyber Security Relevance

Understanding TCP and UDP is important for:

- Network traffic analysis
- Firewall rules
- Port scanning
- Incident investigation
- Network monitoring
- Packet analysis

## What I Learned

TCP focuses on reliable and ordered communication, while UDP focuses on lightweight and faster communication without guaranteed delivery.
