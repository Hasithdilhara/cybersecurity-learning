# DHCP

## What is DHCP?

DHCP (Dynamic Host Configuration Protocol) automatically provides network configuration to devices on a network.

## Information Provided by DHCP

A DHCP server can provide:

- IP address
- Subnet mask
- Default gateway
- DNS server

## Basic DHCP Process

The common DHCP process is known as DORA:

1. Discover
2. Offer
3. Request
4. Acknowledge

## Example

When a laptop connects to a Wi-Fi network, it can request network configuration from a DHCP server.

The DHCP server may provide:

- IP Address: 192.168.1.20
- Subnet Mask: 255.255.255.0
- Default Gateway: 192.168.1.1
- DNS Server: DNS server address

## Cyber Security Relevance

Understanding DHCP is useful for:

- Network troubleshooting
- Network monitoring
- Identifying devices
- Investigating suspicious network activity
- Understanding local network configuration

## What I Learned

DHCP automatically assigns network configuration to devices, making network management easier.
