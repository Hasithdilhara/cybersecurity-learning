# OSI Model

## What is the OSI Model?

The Open Systems Interconnection (OSI) model is a conceptual framework used to understand how network communication works.

It divides network communication into seven layers.

## The Seven Layers

| Layer | Name | Main Function |
|---|---|---|
| 7 | Application | Provides network services to applications |
| 6 | Presentation | Handles data format, encryption, and compression |
| 5 | Session | Establishes and manages communication sessions |
| 4 | Transport | Provides end-to-end communication using TCP or UDP |
| 3 | Network | Handles IP addressing and routing |
| 2 | Data Link | Handles frames and MAC addressing |
| 1 | Physical | Transmits raw bits through physical media |

## Easy Memory Trick

All People Seem To Need Data Processing

Application → Presentation → Session → Transport → Network → Data Link → Physical

## Security Relevance

- Layer 7: Application and web security
- Layer 4: TCP/UDP and port analysis
- Layer 3: IP traffic, routing, and network security
- Layer 2: MAC and ARP-related security
- Layer 1: Physical security
