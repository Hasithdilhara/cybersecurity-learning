# Network Basics

## What is a Network?

A network is a group of connected devices that can communicate with each other and share information or resources.

## Client and Server

### Client

A client is a device or application that requests a service.

Examples:
- Web browser
- Laptop
- Mobile phone

### Server

A server is a system that provides services or resources to clients.

Examples:
- Web server
- DNS server
- File server

## Common Network Devices

### Switch

A switch connects devices within a local network and forwards network traffic to the appropriate device.

### Router

A router connects different networks and forwards traffic between them.

### Firewall

A firewall monitors and controls network traffic based on security rules.

## LAN and WAN

### LAN

A Local Area Network (LAN) covers a relatively small area such as a home, school, or office.

### WAN

A Wide Area Network (WAN) connects networks across larger geographical areas.

## What I Learned

- A network allows devices to communicate.
- Clients request services from servers.
- Switches connect devices within a network.
- Routers connect different networks.
- Firewalls help control and protect network traffic.
- LANs cover smaller areas, while WANs cover larger areas.
